# 源更新维护指南

> 本指南固定桃子影视 App 的源更新流程，避免每次优化都重新读源码。
> 适用仓库：`Hippo1096/taozi-video`（原 `webhtv-offline`）
> 本地副本：`003repos/071801-桃子影视`

## 1. 仓库结构速查

```text
app/src/main/assets/
├── config.json          # 默认配置：无网盘认证源
├── peach-advanced.json  # 进阶配置：默认配置 + 网盘/认证源
├── spider.jar           # 内置爬虫 Jar
├── peach_logo.png       # App Logo
├── list.txt             # 内置 IPv4 直播源（本地兜底）
└── radio.txt            # 内置电台源（本地兜底）
```

两份配置通过 App 内 **设置 → 备份恢复** 切换：
- 日常使用默认配置，避免网盘扫码/登录失败。
- 需要网盘搜索、阿里/夸克/UC/百度盘聚合时，导入进阶配置。

## 2. FongMi 源码更新

### 2.1 关键事实

- 本项目 **不是** FongMi/TV 的 Git fork，而是基于 FongMi 源码二次魔改后导入的新仓库。
- 因此不能直接用 `git pull upstream` 合并，需要手动对比合并。
- 上游分支：`https://github.com/FongMi/TV.git` 的 `fongmi` 分支。

### 2.2 安全更新步骤

```bash
cd 003repos/071801-桃子影视

# 1. 备份当前 main
git checkout -b backup-$(date +%m%d)
git checkout main

# 2. 拉取上游最新源码
git fetch upstream fongmi

# 3. 在临时目录克隆一份纯净 FongMi
rm -rf /tmp/fongmi-latest
git clone --depth 1 --single-branch --branch fongmi https://github.com/FongMi/TV.git /tmp/fongmi-latest

# 4. 对比，只合并不冲突的通用文件（如 build.gradle、公共库、播放器核心）
# 保留以下自定义文件/目录，不覆盖：
#   app/src/main/assets/config.json
#   app/src/main/assets/peach-advanced.json
#   app/src/main/assets/spider.jar
#   app/src/main/assets/peach_logo.png
#   app/src/main/assets/list.txt
#   app/src/main/assets/radio.txt
#   app/src/main/java/ 中所有含 peach/Peach/OfflineBootstrap/ConfigAdapter 的自定义文件
#   plans/、docs/ 中的项目文档
# 5. 对冲突的 Java 文件，人工决定是否同步 FongMi 的修复或保留本仓库魔改逻辑
```

### 2.3 冲突处理原则

| 文件类型 | 处理方式 |
|---|---|
| 纯 FongMi 通用代码 | 直接覆盖 |
| 桃子影视自定义文件（logo/config/引导类） | 保留，不覆盖 |
| 既在 FongMi 更新又被本仓库修改 | 人工合并，优先保留用户交互和离线封装逻辑 |

## 3. 饭太硬源重新拉取与拆分

### 3.1 目标

- 从饭太硬获取最新 TVBox 配置。
- 拆成 **无网盘源** 和 **有网盘源** 两份配置。
- 无网盘源作为 `config.json`，有网盘源作为 `peach-advanced.json`。

### 3.2 当前入口

饭太硬主接口可能返回 HTML 导航页或二维码图片，实际配置需点击 App 内 **点播源设置 → 转换** 解码图片获得。常见入口：

- `http://www.饭太硬.cc/tv`
- `http://fty.xxooo.cf/tv`
- 导航页中可能包含 `https://cdn09022024.gitlink.org.cn/api/v1/repos/xxooo/in/raw/in.bmp` 等图片配置

### 3.3 自动化拆分脚本

当获取到原始 `config.json` 后，使用以下 Python 逻辑拆分：

```python
import json
from pathlib import Path

pan_names = {
    '🐟盘她┃三盘',
    '👻盘它┃三盘',
    '🦋米搜┃夸父',
    '😻夸搜┃夸父',
    '🙀盘搜┃阿狸',
    '😹易搜┃阿狸',
    'AList┃网盘',
}

raw = json.loads(Path('config-饭太硬-原始.json').read_text(encoding='utf-8'))

# 移除成人源（教师场景默认剔除）
 adult_keywords = ['adult', '18+', 'av', '福利', '成人']
 def is_adult(s):
     text = f"{s.get('name','')} {s.get('api','')}".lower()
     return any(k in text for k in adult_keywords)

sites = [s for s in raw['sites'] if not is_adult(s)]
default_sites = [s for s in sites if s.get('name') not in pan_names]
advanced_sites = sites

# 强制使用本地资源
raw['spider'] = 'assets://spider.jar'
raw['logo'] = 'assets://peach_logo.png'

default_cfg = {**raw, 'sites': default_sites}
advanced_cfg = {**raw, 'sites': advanced_sites}

Path('app/src/main/assets/config.json').write_text(
    json.dumps(default_cfg, ensure_ascii=False, indent=2), encoding='utf-8')
Path('app/src/main/assets/peach-advanced.json').write_text(
    json.dumps(advanced_cfg, ensure_ascii=False, indent=2), encoding='utf-8')
```

### 3.4 拆分规则

- **无网盘源** = 原始配置去掉以下 7 个网盘/认证源：
  - `🐟盘她┃三盘`、`👻盘它┃三盘`、`🦋米搜┃夸父`、`😻夸搜┃夸父`
  - `🙀盘搜┃阿狸`、`😹易搜┃阿狸`、`AList┃网盘`
- **有网盘源** = 原始配置全部保留。
- 成人源一律剔除。
- 两个配置 `spider` 和 `logo` 都指向本地 `assets://`。

### 3.5 当饭太硬在线入口不可用时

若 `curl` 返回 HTML 跳转或图片，说明接口正在使用图片/二维码混淆：

1. 使用 App 内 **点播源设置 → 转换** 按钮解码出真实 JSON。
2. 将解码后的 JSON 保存为 `002过程/桃子源整理/001原始/config-饭太硬-原始.json`。
3. 运行上面拆分脚本，覆盖 `config.json` 和 `peach-advanced.json`。
4. 缓存旧版 `config-饭太硬-原始.json` 作为备用真源，即使在线入口短期不可用也能重新生成配置。

## 4. 直播源内置

### 4.1 原则

- 直播源必须 **内置本地兜底**，避免远程接口失效导致 TV 端直播完全不可用。
- `config.json` 和 `peach-advanced.json` 的 `lives` 列表保持相同，两份配置共用一套直播源。

### 4.2 当前内置方案

- `app/src/main/assets/list.txt`：IPv4 电视直播源（M3U/TXT 格式均可）。
- `app/src/main/assets/radio.txt`：电台直播源。
- `lives` 中第一条为本地兜底：

```json
{
  "name": "初秋语•ipv4",
  "type": 0,
  "url": "./list.txt",
  "playerType": 2,
  "epg": "http://epg.cdn.loc.cc/?ch={name}&date={date}",
  "logo": "https://live.fanmingming.com/tv/{name}.png"
}
```

### 4.3 更新直播源

```bash
# 下载可靠 IPV4 直播源（BurningC4/Chinese-IPTV 可直连）
curl -L -A "Mozilla/5.0" \
  -o app/src/main/assets/list.txt \
  "https://raw.githubusercontent.com/BurningC4/Chinese-IPTV/master/TV-IPV4.m3u"

# 更新 radio.txt 中电台地址（手动维护或从公开电台源复制）
```

### 4.4 推荐在线备用源

以下在线源可作为 `lives` 中排在本地兜底之后的备选：

- `https://tv.iill.top/m3u/Gather`
- `https://live.fanmingming.com/tv/m3u/ipv6.m3u`
- `https://github.moeyy.xyz/https://raw.githubusercontent.com/YueChan/Live/main/IPTV.m3u`
- `https://agit.ai/Yoursmile7/TVBox/raw/branch/master/live.txt`

在线源失效时，本地 `list.txt` 仍可播放基础频道。

## 6. 常见坑

| 现象 | 原因 | 处理 |
|---|---|---|
| 饭太硬 `curl` 返回 HTML | 接口使用导航页/图片混淆 | 用 App 内转换按钮或找备用直链 |
| 直播加载失败 | 在线直播源失效或本地 `list.txt` 缺失 | 检查 `list.txt` 是否存在，优先用本地兜底 |
| 网盘源无法播放 | 未登录对应网盘/无会员 | 切换到进阶配置并扫码登录，或回默认配置 |
| 更新 FongMi 后配置丢失 | 合并时覆盖了 `assets/*.json` | 合并前备份，只合并不冲突的通用代码 |
| 成人源出现 | 新配置混入未过滤源 | 拆分脚本中加入 `adult_keywords` 过滤 |
